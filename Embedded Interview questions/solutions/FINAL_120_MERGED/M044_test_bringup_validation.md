## Step 0 — Clarifying questions

## Step 1 — Requirements

- Register fake layer behind function pointers
- Fault inject: timeout, NACK, CRC bad
- Timing tests with mock tick
- CI: build all + run host tests

## Step 2 — ASCII block diagram

## Step 4 — Failure modes

- Fakes diverge from silicon — periodic HIL
- Flaky timing tests — deterministic tick
- Missing cross-compile in CI — link errors in field

## Step 5 — Tradeoffs table

| Test level | Speed | Fidelity |
|---|---:|---:|
| Host unit | fast | low |
| HIL | slow | high |
| Field soak | slowest | real |
