## Step 3 — Complete solution (compilable C)

```c
#include <stdint.h>
#include <stddef.h>
typedef struct {
    int32_t buf[8];
    int idx;
    int32_t sum;
}
ma_t;
int32_t ma_push(ma_t *m,int32_t v) {
    m->sum-=m->buf[m->idx];
    m->buf[m->idx]=v;
    m->sum+=v;
    m->idx=(m->idx+1)%8;
    return m->sum/8;
}
```
