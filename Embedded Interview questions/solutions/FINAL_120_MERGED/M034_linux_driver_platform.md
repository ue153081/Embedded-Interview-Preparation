## Step 3 — Follow-ups with answers

**Q: ioctl vs sysfs?**  
**A:** ioctl for complex ops; sysfs for simple config attributes.

**Q: Device Tree role?**  
**A:** Hardware description in kernel — driver reads properties at probe.

## Step 4 — 60-second script

Userspace talks to drivers via ioctl for commands, mmap for buffers, poll to sleep until data. Platform drivers match Device Tree compatible strings, use devm_* for auto cleanup, and implement suspend/resume with runtime PM refs balanced.
